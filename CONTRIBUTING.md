# Contributing

Thanks for your interest in LeeziePass.

This repository only hosts the compiled release and its documentation; the
source code is maintained privately. **Pull requests are therefore not
accepted.**

What is welcome:

- **Bug reports** — open an [issue](../../issues/new/choose) using the bug
  report template.
- **Feature requests and suggestions** — open an issue describing what you
  would like and why.
- **Security problems** — do *not* open an issue; see [SECURITY.md](SECURITY.md).
